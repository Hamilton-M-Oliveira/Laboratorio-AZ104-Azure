## Estrutura de Pastas

- **Azure CLI/** → Scripts em shell (`.sh`) para operações via Azure CLI.
- **ARM-Bicep/** → Arquivos `.bicep` para provisionamento declarativo de recursos.
- **Terraform/** → Arquivos `.tf` para gerenciamento de infraestrutura multi-cloud.
- **PowerShell/** → Scripts `.ps1` para automação administrativa no Azure.

## Objetivo

O objetivo é comparar e praticar diferentes abordagens para:
- Criar e gerenciar **usuários internos e externos**.
- Configurar **grupos e funções (roles)**.
- Implementar **MFA (Multi-Factor Authentication)**.
- Configurar **SSPR (Self-Service Password Reset)**.
- Gerenciar **licenças** e **acesso condicional**.

## Como usar

1. Escolha a pasta da tecnologia desejada (Azure CLI, Bicep, Terraform ou PowerShell).
2. Execute o script correspondente ao recurso que deseja configurar.
3. Compare os resultados entre as diferentes ferramentas para entender vantagens e limitações.


Esse README serve como guia inicial para quem abrir o repositório e quiser entender rapidamente o propósito e a organização do cenário.
